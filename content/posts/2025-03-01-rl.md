The kiddo and I worked through this [Godot Reinforcement Learning tutorial](https://huggingface.co/learn/deep-rl-course/en/unitbonus3/godotrl), and (after some troubleshooting to get [onnx](https://github.com/onnx/onnx) to install) it worked! We trained a model to be able to play a circular pong game. 

I don't necessarily understand most of what I did there, for example why I would pick "Stable Baselines" vs " Clean RL", but it definitely seems like something worth experimenting with some more. It might be fun to use to use RL to improve the the opponent in [The Zummoning](https://rosskarchner.itch.io/the-zummoning).

It's a shame that in order to use a model in-game, you need to use the .NET version of Godot, which (apparently) [can't yet export to the web](https://godotengine.org/article/platform-state-in-csharp-for-godot-4-2/#web).
