{{< game name="The Invisible Alligator" date="June 2025" url="https://rosskarchner.itch.io/the-invisible-alligator" video="/uploads/2025/screencast-from-2025-06-23-10-21-18.mp4" poster="/uploads/2025/10acfbe81f.png" >}}
An unpolished but challenging turn-based puzzle, about an alligator sneaking around and eating ducks. Made for [Godot Wild Jam 82](https://itch.io/jam/godot-wild-jam-82). [Play on itch.io](https://rosskarchner.itch.io/the-invisible-alligator)
{{< /game >}}

{{< game name="Pinball Putt" date="December 2024" url="https://rosskarchner.itch.io/pinball-putt" video="/uploads/2024/screencast-from-2024-12-03-15-05-47.webm" >}}
A mini-golf/pinball mashup where you need to earn enough points to pass a level, without running out of strokes. Made in collaboration with Benjamin Karchner for the [2024 1-Button Game Jam](https://itch.io/jam/1-button-jam-2024). [Play on itch.io](https://rosskarchner.itch.io/pinball-putt).
{{< /game >}}

{{< game name="Quack Circuits" date="August 2024" url="https://rosskarchner.itch.io/quack-circuits" video="/uploads/2024/screencast-from-2024-08-18-18-49-08.mp4" >}}
This is _admittedly_ a strange one. Help a scared-of-the-dark duck escape to freedom by… solving circuit puzzles? Created in 9 days for Godot Wild Jam #72. Ranked 21 (out of 156) in the "originality" category. [Play on itch.io](https://rosskarchner.itch.io/quack-circuits)
{{< /game >}}

{{< game name="The Last Stan" date="June 2024" url="https://rosskarchner.itch.io/the-last-stan" video="/uploads/2024/screencast-from-2024-06-03-16-57-30.mp4" >}}
A simple platformer with typing challenges. Created in 10 days for the 2024 GameDev.tv jam, where it ranked 59th (out of over 1000) in the "mechanics" category. [Play on itch.io](https://rosskarchner.itch.io/the-last-stan).
{{< /game >}}

{{< game name="The Zummoning" date="April 2024" url="https://rosskarchner.itch.io/the-zummoning" video="/uploads/2024/zz.webm" >}}
Play and combine cards to summon creatures that march towards the enemy. Created in nine days for Godot Wild Jam #68. An earlier version was also submitted to Ludum Dare 55. Made with Godot 4. [Play on itch.io](https://rosskarchner.itch.io/the-zummoning)
{{< /game >}}

{{< game name="Brakes Escape" date="February 2024" url="https://rosskarchner.itch.io/brakes-escape" video="/uploads/2024/brakes.mp4" >}}
Jump as high as you can to escape the rising water. Created in nine days for Godot Wild Jam #66, where it ranked 4th in the "controls" category and 14th in "fun" (out of 158 entries). Made with Godot 4. [Play on itch.io](https://rosskarchner.itch.io/brakes-escape).
{{< /game >}}

{{< game name="twenty thousand milliseconds" date="December 2023" url="https://rosskarchner.itch.io/twenty-thousand-milliseconds" video="/uploads/2024/screencast-from-2024-05-08-14-36-26.webm" >}}
A submission to the [20 SECOND GAME JAM 2023](https://itch.io/jam/20-second-game-jam-2023), which tests your ability to differentiate between time intervals of less than 1 second. Made with Godot 4. [Play on itch.io](https://rosskarchner.itch.io/twenty-thousand-milliseconds).
{{< /game >}}

{{< game name="Don't get Crushed" date="October 2023" url="https://rosskarchner.itch.io/dont-get-crushed" video="/uploads/2023/crushed-1016.mp4" >}}
Created in 72 hours for Ludum Dare 54, where the theme was "limited space". Made with Godot 3. [Play on itch.io](https://rosskarchner.itch.io/dont-get-crushed)
{{< /game >}}

{{< game name="Beat Game" date="July 2023" url="https://rosskarchner.itch.io/beat-game" video="/uploads/2024/screencast-from-2024-05-08-14-32-33.webm" >}}
